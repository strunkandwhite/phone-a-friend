# Panel UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the menu with a panel. Today's friend becomes the headline, logging a contact becomes type-to-search, and the icon becomes a phone.

**Architecture:**
- The search ranking is a pure function in the Foundation-only `FriendQueue` library, tested on Linux.
- The panel is a SwiftUI view in the macOS-only `PhoneAFriend` target, shown through `MenuBarExtra` with `.menuBarExtraStyle(.window)`.
- No rules in `AppState`/`DailyEngine` change.

**Tech Stack:** Swift 5.9 tools / Swift 6.1 toolchain, XCTest, SwiftUI, AppKit.

**Spec:** `docs/superpowers/specs/2026-11-14-panel-ui-design.md`, which amends `docs/superpowers/specs/2026-11-14-phone-a-friend-design.md`.

## Review Focus

1. **Accents in either direction:** the query "José" must find "Jose" and the query "jose" must find "José Ruiz". Test in Task 1.
2. **A query that is only spaces** behaves like an empty query and shows today's logs, not every name. Test in Task 1.
3. **A friend logged today and then removed from the list** doesn't appear in the empty-query list, because results only ever contain current names. Test in Task 1.
4. **Return with no matches** does nothing and keeps the typed text, so the owner can fix a typo. Checklist in Task 2.
5. **Long names and long result lists** truncate on one line and scroll instead of stretching the panel. Checklist in Task 2.

### Task 1: Search ranking in `FriendQueue`

**Files:**
- Create: `Sources/FriendQueue/FriendSearch.swift`
- Create: `Tests/FriendQueueTests/FriendSearchTests.swift`

**Interfaces:**
- Produces: `public enum FriendSearch { static func results(query: String, names: [String], loggedToday: Set<String>) -> [String] }`

Rules:
- **Empty or whitespace-only query:** the current names that are in `loggedToday`, sorted alphabetically.
- **Otherwise,** fold the trimmed query and each name case- and diacritic-insensitively.
  - A name matches if its folded form contains the folded query.
  - **Word-start matches** come first: the folded name starts with the query, or contains `" " + query`. Then the other matches.
  - Each group is sorted with `localizedStandardCompare`.

- [ ] **Step 1: Write the failing tests.**

```swift
let names = ["Rosamund Pike", "Sam Ortiz", "Pam Samuels", "José Ruiz", "Lee"]
testEmptyQueryShowsOnlyLoggedToday     // results("", names, ["Sam Ortiz","Lee"]) == ["Lee", "Sam Ortiz"]
testWhitespaceQueryActsEmpty           // results("   ", names, ["Lee"]) == ["Lee"]
testEmptyQueryNoLogsIsEmpty            // results("", names, []) == []
testLoggedButRemovedNameIsNotShown     // results("", ["Lee"], ["Gone", "Lee"]) == ["Lee"]
testWordStartRanksAboveContains        // results("sam", names, []) == ["Pam Samuels", "Sam Ortiz", "Rosamund Pike"]
testIgnoresCaseAndAccentsBothWays      // results("jose", names, []) == ["José Ruiz"]; results("JOSÉ", ["Jose"], []) == ["Jose"]
testMultiWordQueryMatches              // results("sam or", names, []) == ["Sam Ortiz"]
testQueryIsTrimmed                     // results("  lee ", names, []) == ["Lee"]
testNoMatchesIsEmpty                   // results("zz", names, []) == []
```

- [ ] **Step 2: Run `scripts/test-linux.sh --filter FriendSearchTests`.** Expected: a compile failure (`FriendSearch` is undefined).

- [ ] **Step 3: Implement `FriendSearch.results`.** Fold with `folding(options: [.caseInsensitive, .diacriticInsensitive], locale: nil)`.

- [ ] **Step 4: Run `scripts/test-linux.sh`.** Expected: all tests pass (53 existing plus 9 new).

### Task 2: Panel, phone icon, refresh on open

This task can't be compiled in the sandbox. Write it against the named APIs, run `swiftc -parse` on the app sources inside the `swift:6.1` image, and confirm the Linux suite still passes. The owner runs the checklist.

**Files:**
- Modify: `Sources/PhoneAFriend/PhoneAFriendApp.swift` (use `PanelView` and `.menuBarExtraStyle(.window)`)
- Modify: `Sources/PhoneAFriend/StatusIcon.swift` (symbol becomes `phone.fill`; replace the force-unwrap with `?? NSImage()`)

**Interfaces:**
- Consumes:
  - From `AppModel`: `state`, `names`, `errorLine`, `openAtLogin`, `openAtLoginFailed`, `today`, `loggedToday`, `refresh()`, `answer(_:)`, `toggleLog(_:)`, `openFriendList()`, `setOpenAtLogin(_:)`
  - `DisplayText.lastContact`
  - `FriendSearch.results` (Task 1)

- [ ] **Step 1: Write `PanelView`.** It's `@MainActor struct PanelView: View` with `@ObservedObject var model: AppModel`, `@State private var query = ""` and `@FocusState private var searchFocused: Bool`. It's a `VStack(alignment: .leading)`, 300pt wide with padding, containing:
  1. **Error line,** if any: `.font(.caption)`, `.foregroundStyle(.red)`.
  2. **Today section.** With a pick:
     - `Text("TODAY")` in `.caption` and `.secondary`.
     - `Text(verbatim: pick.friend)` in `.title2.bold()`, one line, truncating at the tail.
     - `Text(verbatim: DisplayText.lastContact(pick.priorRecord, today: model.today))` in `.secondary`.
     - An `HStack` with the Contacted button in `.borderedProminent` and Not today in `.bordered`. Each label gets a `✓ ` prefix when it's the current answer. Clicking the current answer calls `model.answer(nil)`; clicking the other calls `model.answer(that)`.
     - With no pick: the empty-list text and an `Edit friend list…` button.
  3. A `Divider`.
  4. **Search section.**
     - `Text("Log a contact")` in `.headline`.
     - `TextField("Type a name…", text: $query)`, `.textFieldStyle(.roundedBorder)`, `.focused($searchFocused)`.
       - `.onSubmit`: if `model.searchResults(for: query).first` exists, call `model.toggleLog` on it and clear `query`. Otherwise do nothing.
     - Results go in a `ScrollView` with `.frame(maxHeight: 200)`. Each result is a full-width plain `Button` row: the name (one line, truncating at the tail), a `Spacer`, and `✓ today` in `.secondary` when the name is in `model.loggedToday`. Clicking it calls `model.toggleLog(name)`.
     - The section is hidden when `model.names` is empty.
  5. A `Divider`.
  6. **Footer.** An `HStack`: `Button("Edit list…")`, `Spacer`, `Toggle("Open at login", …)` with `.toggleStyle(.checkbox)`, `Button("Quit")`. Under it, the existing failure note when `model.openAtLoginFailed`.
  - **`.onAppear`:** call `model.refresh()`, clear `query`, then `DispatchQueue.main.async { searchFocused = true }`. The async hop lets the panel's window become key first.
